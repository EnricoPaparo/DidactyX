# Campioni della verifica tecnica

Evidenze sintetiche della prova del 15 novembre 2026. Contesto scolastico ed esempi sono fittizi. Il [rapporto](../../../TECHNICAL_FEASIBILITY.md) descrive metodi, risultati e limiti.

Il [PDF](didactyx-feasibility-sample.pdf) contiene due lezioni collegate, una mappa concettuale, uno schema vettoriale e un'illustrazione prodotta dal tool immagini nativo di Codex.

I file JSON conservano i contenuti generati, la fixture con errore deliberato, la revisione e gli esiti dei controlli. `manifest.json` riporta dimensioni e impronte dei campioni. Non sono inclusi credenziali, risposte complete dell'account o checkpoint delle sessioni.

Le istruzioni per ripetere le prove sono in [experiments/feasibility](../../../../experiments/feasibility/README.md). Una nuova esecuzione può produrre contenuti e tempi diversi e, per le prove generative, utilizza la disponibilità dell'account collegato.
